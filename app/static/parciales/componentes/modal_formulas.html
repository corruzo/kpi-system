Guía de fórmulas

Reglas básicas

  • Use las claves de las variables y constantes tal como aparecen en los botones.
  • Operadores: + − × ÷, ^ potencia, % resto, // división entera, paréntesis.
  • Comparaciones: > < >= <= == !=; lógica: and or not.
  • Para evitar «división entre cero» use si(b > 0, a / b, 0) o div(a, b, 0).
  • Decimales con punto: 0.5. Máximo 1000 caracteres.
